# Orders & Customers Analysis

This project uses **Pandas** to analyze customer orders.

## Features
- Merges `orders` and `customers` tables by `customer_id`.
- Calculates:
  - Total revenue per customer
  - Total revenue per city
  - Average order value per customer
  - Top 2 customers by spending
  - Customers spending more than $250
  - Total revenue per date

## Usage
Run the script directly with Python:
```bash
python main.py
